# GPT-2 Text Generation using Fine-Tuning

### Prodigy InfoTech — Generative AI Internship | Task 01

A Generative AI project that fine-tunes the pretrained **GPT-2** language model on a custom AI-focused dataset and generates contextually relevant text from user prompts.

---

## 📌 Project Overview

This project demonstrates the complete workflow of fine-tuning a pretrained Large Language Model (LLM) for text generation.

The pretrained GPT-2 model is fine-tuned using a custom dataset containing concepts related to:

- Artificial Intelligence
- Machine Learning
- Generative AI
- Natural Language Processing
- Transformers
- Large Language Models
- GPT-2
- Tokenization
- Fine-tuning
- Text Generation

After training, the fine-tuned model accepts a text prompt and generates a continuation based on patterns learned from the training data.

---

## 🎯 Objective

The main objectives of this project are to:

- Understand the fundamentals of Generative AI and LLMs.
- Work with a pretrained GPT-2 causal language model.
- Prepare and tokenize a custom text dataset.
- Fine-tune GPT-2 using Hugging Face Transformers.
- Generate text from user-provided prompts.
- Experiment with sampling-based generation.
- Understand parameters such as Temperature and Top-P.
- Build a reproducible end-to-end text-generation pipeline.
